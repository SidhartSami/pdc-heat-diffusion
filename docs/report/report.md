### Abstract
This report presents the design, implementation, and empirical performance evaluation of a hybrid distributed- and shared-memory (MPI + OpenMP) solver for the 2D and 3D heat diffusion equations using an explicit Forward-Time Central-Space (FTCS) finite-difference scheme.
